# DOGS 58

This is a marketplace storefront powered by [Prometora](https://prometora.com).

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see your store.

## Environment Variables

Copy `.env.example` to `.env.local` and fill in your store ID:

```bash
STORE_ID=your-store-id
PROMETORA_API_URL=https://prometora.com
```
